About

Think smaller.

Spliinter is a free, real-time multiplayer word game. Everyone in a room sees the same long word and tries to find smaller words made from its letters. A word scores only when one player finds it.

How a game works

Players choose a username, create or join a room, and wait for the host to start. Rooms hold between two and twelve players. The host chooses between one and ten rounds; the default round lasts two minutes, although the server’s round duration can be configured.

During a round, each player submits words privately. At the end, the server reveals the lists together. A word found by exactly one player scores one point; a word found by two or more players scores zero for everyone who submitted it. Round points accumulate through the game, and medals are awarded for the top non-zero round scores, with ties sharing a rank.

Why unique words score

The scoring rule makes the reveal part of the game: familiar words may be shared, while a less obvious answer can earn the same single point regardless of length. Players can submit as many valid words as they can find during the round. There is no extra score for using more letters.

For practical instructions, including examples of valid and invalid submissions, see How to play. For a search routine, see Word game strategy.

How the game is built

The browser app communicates with a Node.js server using Socket.IO. The server owns rooms, player state, timers, validation and scoring. It sends each player a tailored view of the game: during a round, a player sees their own words and other players’ word counts, not their actual submissions.

  • Deadline: the server sets the end time and rejects submissions received after it.
  • Letter inventory: a submitted word cannot use any letter more times than the base word contains it.
  • Dictionary: the server loads the word-list package once at startup and checks words against that list. The implementation also adds three explicit words.
  • Scoring: the server compares each player’s accepted words after the round and awards one point only when exactly one player submitted a word.
  • Reconnects: a per-tab token allows a player to attempt to resume while the corresponding in-memory room still exists. It cannot restore a room after the server process restarts or the room closes.

How base words are selected

In the default configuration, round words are selected from the game dictionary and are between nine and twelve letters long. Candidates that are only inflections of shorter dictionary words are filtered out, and a candidate must have at least 120 valid smaller words according to the server’s letter-count and dictionary rules. A separate BASE_WORDS=common configuration uses a hand-picked pool of familiar words; the fallback pool is also used if random selection cannot fill a game.

Dictionary and word decisions

The underlying word list is provided by the word-list npm package. It is a general-purpose list, not a custom competition lexicon. That means a valid answer may be unfamiliar, and accepted words are determined by the list and the game’s letter rules rather than by a separate house dictionary.

The game does not record an editorial list of rejected words or publish monthly rejection rankings. If you think a word should be reviewed, email the word and the base word it was tried against; that gives us the information needed to reproduce the check.

Data and availability

Room codes, usernames, connection state, current submissions and scores are kept in server memory so multiplayer games can run. They are not stored in a game database, and a server restart clears active game state. A reconnect token is kept in the current browser tab’s session storage. Optional Google Analytics measurement is disabled unless you accept optional cookies; the Privacy Policy explains what is sent.

Spliinter’s real-time game and its static information pages are served by the same application. When that service is starting or unavailable, the game may take time to connect; reconnecting cannot recover an in-memory room after a restart.
