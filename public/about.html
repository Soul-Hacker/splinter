About the game

Think smaller.

Spliinter is a real-time multiplayer word game about finding as many smaller words as possible inside one long word.

How it works

Create or join a room, wait for the host to start, and submit words before the clock runs out. Words found by only one player score. Words found by two or more players cancel out for everyone.

Built for fair play

The server validates words, scores rounds, controls the timer, and keeps other players' submissions private until the round ends. No account is required to play.

Original content

Spliinter's game experience, interface, rules, and supporting materials are created for this project. Dictionary data is supplied by the open-source word-list package and is used for gameplay validation.

Contact

Ideas, accessibility feedback, and support requests are welcome at contact@spliinter.in.
